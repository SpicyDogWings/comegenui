CuTable - Fruits Store Demo

Single-click to edit. The pencil icon turns GREEN on valid edit or RED on validation failure.

Validation Rules:

  • Fruit: Must be at least 3 characters (validator function)
  • Stock: Only numbers allowed (RegExp: /^\d+$/)
  • Send:
    • RegExp: Only numbers (/^\d+$/)
    • Validator: Must be <= Stock (uses row data)
  • ID: Not editable

Note: Send column uses BOTH RegExp + Validator together.

Try These:

  • Valid Send: Change Apple's Send to "80" (<= 100 stock) → Green ✓
  • Invalid Send (exceeds stock): Change Apple's Send to "150" (> 100 stock) → Red ✗
  • Invalid Send (not a number): Change Apple's Send to "fifty" → Red ✗ (fails RegExp)
  • Valid Fruit: Change "Apple" to "Pear" → Green ✓
  • Invalid Fruit: Change "Apple" to "A" (too short) → Red ✗
  • Valid Stock: Change stock to "200" → Green ✓
  • Invalid Stock: Change stock to "one hundred" → Red ✗
