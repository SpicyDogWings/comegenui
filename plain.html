CuTable - Edit Validation Feedback

Single-click to edit. The pencil icon turns GREEN on valid edit or RED on validation failure.

Try These:

  • Valid: Change "Apple" to "Pear" → Green ✓
  • Invalid: Change "Apple" to "A" (too short, min 3 chars) → Red ✗
  • Valid: Change stock "100" to "200" → Green ✓
  • Invalid: Change stock "100" to "one hundred" (numbers only) → Red ✗
  • Valid: Change email to "test@domain.com" → Green ✓
  • Invalid: Change email to "not-an-email" → Red ✗
