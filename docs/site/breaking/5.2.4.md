# Breaking changes — hasta **5.2.4**

Salto: **5.2.3 → 5.2.4**. Si generás el CSS desde `comegen.config.json` o desde el Theme Builder,
no tenés que hacer nada: el generador ya emite los tokens nuevos. Si definís los tokens **a mano**,
leé los puntos 1 y 2.

## 1. Las variantes usan tokens nuevos

Cada color necesita ahora:

- `--cu-color-{color}-solid-text` — texto de `solid` y `none` (el polo negro/blanco de máximo
  contraste contra el relleno y sus estados).
- `--cu-color-{color}-text-on-ghost` — texto sobre el tinte `ghost` (hasta 20 %).
- `--cu-color-{color}-text-on-soft` — texto sobre el tinte `soft` (hasta 35 %).
- `--cu-color-{color}-text-on-subtle` — texto sobre el tinte `subtle` (hasta 30 %).

**Si no los definís**: esas variantes no se rompen, pero el texto cae al color heredado (pierde el
contraste calculado). `solid` ya no usa blanco fijo sobre el color: usa `-solid-text`.

```css
:root {
  --cu-color-primary: #0f62fe;
  --cu-color-primary-solid: #0f62fe;       /* mismo base: ya no se oscurece */
  --cu-color-primary-solid-text: #ffffff;  /* negro o blanco, el de más contraste */
  --cu-color-primary-text: #0f62fe;        /* sólo se mide contra surface */
  --cu-color-primary-text-on-ghost: #0b4fc4;
  --cu-color-primary-text-on-soft: #0a469f;
  --cu-color-primary-text-on-subtle: #083a80;
}
```

## 2. `-solid` conserva el color del tema y `-text` cambia de base de medición

- `--cu-color-{color}-solid` (y sus estados `-solid-hover` / `-solid-active`) es el **color base del
  tema tal cual**. Antes el generador lo oscurecía o aclaraba para forzar contraste con blanco; ahora
  el contraste lo resuelve el **texto** (`-solid-text`). Visualmente, los rellenos `solid` de los
  temas oscuros se ven más brillantes/saturados que antes.
- `--cu-color-{color}-text` se mide **sólo contra `--cu-color-surface`** (casos `ghost`, `outlined` y
  `link`). Para fondos tintados (`ghost`/`soft`/`subtle`) usá `-text-on-ghost`, `-text-on-soft` y
  `-text-on-subtle`; el `-text` anterior ya no está garantizado sobre el tinte.
- Cuando el relleno `solid` queda a menos de 3:1 de la superficie, los componentes dibujan el borde
  `--cu-color-{color}-border` para delimitar el control.

## 3. El CSS exportado por el Theme Builder aplica sin `data-theme`

`generateThemeCSS` emite `:root` (el tema activo, sin atributo) además de `[data-theme="…"]` (para
cambiar de tema). Si comparabas el CSS exportado esperando sólo el selector `[data-theme]`, ahora
trae los dos. No hay que hacer nada: es aditivo.
