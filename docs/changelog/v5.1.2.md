# Changelog — v5.1.2

_Release de reemplazo de `v5.1.1`: mantiene la misma superficie pública y suma los fixes
pendientes. Estado: **en preparación** — es la `latest` del sitio, pero todavía no es la versión
final._

## Objetivo

Reemplazar la release publicada con el tag `v5.1.1` por una versión que incluya estos fixes, sin
cambios de compatibilidad para quien ya consume la lib.

## Componentes

**Arreglado**

- `cu-switch`: el atributo/prop `label` ahora renderiza su texto aunque el host no tenga hijos. El
  wrapper CE pasaba siempre un slot `default` vacío, así que el componente interno nunca caía al
  fallback del `label`; ahora sólo pasa el slot cuando el host tiene contenido real (ignora
  espacios y comentarios, y reacciona si el contenido se agrega después del mount). El slot
  `default` sigue teniendo prioridad cuando existe contenido.
