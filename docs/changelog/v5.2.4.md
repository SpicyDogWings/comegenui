# Changelog — v5.2.4

_Delta desde `v5.2.3` (2026-11-03) hasta `release/5.2.4` (2026-11-05). 30 commits._

Release de exportación de tablas y corrección de tokens. Entra **`cu-export-button`**, un botón
reutilizable que genera XLSX/CSV, y `cu-table` deja de sólo avisar el click: **descarga el archivo**
por el mismo core que ahora comparten la tabla, el botón y `cu-cells-importer`. En tokens, `solid`
**conserva el color del tema** en los 15 temas (el contraste lo resuelve el texto, no el fondo),
cada variante tintada tiene su propio token de texto y el CSS exportado del Theme Builder sirve
también sin `data-theme`. `cu-card` estrena el alias `heading` para no arrastrar el tooltip nativo
del atributo `title`.

## ⚠️ Distribución

- **Tokens nuevos requeridos por las variantes.** Si definís los tokens a mano (en vez de generar el
  CSS desde `comegen.config.json`), agregá `--cu-color-{color}-solid-text`,
  `--cu-color-{color}-text-on-ghost`, `--cu-color-{color}-text-on-soft` y
  `--cu-color-{color}-text-on-subtle` para los seis colores. Sin ellos, el texto de las variantes
  `solid`, `ghost`, `soft` y `subtle` cae al color heredado.
- **Cambia la semántica de los tokens existentes:** `-solid` ya **no** oscurece ni aclara el color
  del tema (el relleno es el base tal cual) y `-text` se mide **sólo** contra `surface`. Los
  consumidores con fondos tintados pasan a los tokens `-text-on-*`. Guía de migración:
  [Breaking changes 5.2.4](/breaking/5.2.4).
- **Bundle nuevo:** `CuExportButton.umd.js` / `CuExportButton.js` en las cuatro configs. SheetJS
  viaja dentro del bundle, así que no hay dependencia extra que instalar.
- **CSS exportado del Theme Builder:** emite `:root` además de `[data-theme="…"]`, así el tema
  aplica sin atributo.

## Componentes

**Agregado**

- `cu-export-button` (nuevo): botón que exporta filas a **XLSX** (default) o **CSV** y dispara la
  descarga. Props `data`, `columns` (`key`/`label`/`type`/`format`/`width`/`exportable`), `format`,
  `filename`, `sheet-name`, `delimiter`, `heavy-threshold`, `manual`, `label`, `color`, `variant` y
  `size`. Eventos `trigger` (modo manual), `before-download` (cancelable), `download`, `heavy` y
  `error`; métodos `setData()`, `setOptions()`, `getPayload()` y `download()`. Con `label=""` queda
  sólo el ícono y el nombre accesible sale del formato.
- `cu-table`: props `export-enabled` (muestra el botón) y `export-button` (configuración visual y de
  archivo); métodos `getExportData()` (columnas exportables + valores crudos, `scope: "all"` o
  `"visible"`) y `exportToExcel()`; eventos `before-download`, `export-click` y `export-heavy`.
  `columns[].exportable: false` deja una columna fuera del archivo.
- `cu-card`: prop `heading`, alias preferido de `title`; si vienen ambos, gana `heading`.

**Cambiado**

- `cu-table`: el botón de exportación **descarga** el archivo (antes sólo emitía `export-click`), se
  ubica a la derecha del buscador (si el buscador está apagado, se renderiza solo alineado a la
  derecha) y usa `success`/`solid` por defecto. `exportToExcel()` funciona aunque `exportEnabled` sea
  `false`; `exportButton.disabled` sólo apaga el botón, no el método.
- `cu-cells-importer`: comparte el core de archivos con la tabla y el botón (mismos encabezados,
  formatos y conteos).
- Tokens (15 temas): `-solid` conserva el color base y `-solid-text` es el polo (negro/blanco) de
  máximo contraste contra el relleno y sus estados; las variantes `solid` dibujan el borde `-border`
  (≥ 3:1 contra `surface`) cuando el relleno no se delimita solo. `-text` se mide contra `surface` y
  los tintes usan `-text-on-ghost` (20 %), `-text-on-soft` (35 %) y `-text-on-subtle` (30 %). Se
  corrige la sobre-corrección en temas oscuros (si el base ya supera 4.5:1 se usa tal cual).
  Consumidores actualizados: Button, Badge, Alert, Card, Tabs, Calendar, MonthSliderLabel, Checkbox,
  Switch, Table/AdvancedTable, FileList, FileInput/FileInputZone, Tooltip, Avatar y Tabs.

**Arreglado**

- `cu-card`: `heading` evita el tooltip nativo que el navegador dibuja sobre todo el host cuando el
  CE recibe `title`; `title` se mantiene por compatibilidad.
- Anillo de foco: `Input`, `Textarea`, `Select`, `FileInput`, `FileInputZone`, `FileList` y las
  tarjetas de tema de Home usan `--cu-border-color-focus` (piso 3:1 contra `surface`) en lugar de
  colores sin piso; `Select` apaga el `outline` nativo para no dibujar doble anillo.
- Theme Builder: el **Theme Name** renombra/duplica el tema custom y el JSON/CSS exportado usa ese
  nombre (un nombre de tema incluido se rechaza y el campo vuelve al vigente); el store lo persiste
  sin duplicar el slot `custom`; el panel de colores muestra los valores **aplicados** de `-solid` y
  `-text` leídos del preview; el toast warning usa `-solid` + `-solid-text` (fallback a `surface`).
  Modal y Side Over quedan en el grupo **Avanzado**, al final del panel.
- Markdown: el preview Editorial del Theme Builder y el bloque de Home se renderizan por
  interpolación, así conservan sus saltos de línea (el compilador de plantillas los colapsaba en un
  único heading/párrafo).
