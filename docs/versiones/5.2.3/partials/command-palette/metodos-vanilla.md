| Método | Descripción |
| ------ | ------ |
| `open` | Abre el modal y enfoca el buscador. |
| `close` | Cierra el modal y limpia la búsqueda. |
| `run` | Ejecuta el comando con ese id, sin abrirlo ni cambiar el estado de la paleta. Devuelve el `CommandItem` o `null`. |
| `getCommands` | Devuelve los `CommandItem[]` recibidos en `commands`. |
| `isOpen` | Devuelve `true` si la paleta está abierta. |
